西北民族大学访客预约静态仿真页面（三 HTML 版）

文件说明：
index.html   首页
reserve.html 来校预约页：点击“添加”在本页展开来访人表单，返回回首页
records.html 预约记录页：搜索、列表、详情都在本页切换，返回回首页；搜索区域为 sticky 悬浮
assets/banner.jpg 首页校门图

GitHub Pages 使用：
把 index.html、reserve.html、records.html、assets 文件夹一起上传到仓库根目录，Settings -> Pages -> Deploy from a branch -> main / root。
